Jev Observer 0.1.0 is the first release from the fresh Git history, with verified native packages for Linux, macOS and Windows on x86-64 and ARM64. The dashboard, fonts and SQLite are bundled into one executable; runtime installation needs no Rust, Node.js or database server.

## Install

The following commands download the public release. For private forks, use the [authenticated installation commands](https://github.com/LimePencil/jev-observer/blob/main/docs/installation.md#private-repository-access).

Linux / macOS:

```sh
curl -fsSL https://raw.githubusercontent.com/LimePencil/jev-observer/main/install.sh -o install.sh
sh install.sh --version 0.1.0
export PATH="$HOME/.local/bin:$PATH"
jev-observer --demo
```

Windows PowerShell:

```powershell
Invoke-WebRequest https://raw.githubusercontent.com/LimePencil/jev-observer/main/install.ps1 -OutFile install.ps1
.\install.ps1 -Version 0.1.0
& "$env:LOCALAPPDATA\JevObserver\bin\jev-observer.exe" --demo
```

Open http://127.0.0.1:8765 and sign in with username `observer` and the dashboard token from the file whose path Observer prints. Demo mode contains 720 synthetic requests and makes no provider calls.

## Included features

- Native Windows access-token creation with a protected current-user ACL; permissive token files and reparse points are rejected. The default `.jev-observer` workspace has private inheritable permissions. Custom Windows database paths require a directory restricted to the user, SYSTEM and administrators.
- A PowerShell installer with architecture detection, version pinning, SHA-256 validation and atomic executable replacement. Failed downloads, invalid archives and version mismatches preserve the existing installation.
- Six native release targets: Linux x86-64/ARM64 (static musl), macOS Intel/Apple silicon, and Windows x86-64/ARM64 (MSVC with a static C runtime). Windows uses ZIP packages; Unix uses tar.gz packages. `SHA256SUMS` covers all six.
- Authenticated local dashboards and registered local client tokens, plus session-only or operating-system credential storage for provider keys.
- Encrypted live history with SQLCipher, existing plaintext-history migration, improved credential redaction, proxy header handling and collection-health reporting.
- Dashboard and storage fixes for definition grouping, version comparisons, review labels, concurrent exports and deletion, filter persistence and delayed health samples.
- An MIT license for Observer, with the full notice embedded at `/licenses/jev-observer-MIT.txt`, plus notices for Rust, production web dependencies, SQLCipher, OpenSSL and native bundled components. Font licenses remain separate.
- Application-connection and storage guides, and screenshots captured from the real synthetic demo.

## Upgrade and limits

Stop Observer before upgrading or migrating existing history. Generate and save a 64-character hexadecimal `JEV_OBSERVER_DB_KEY` before live startup, and supply the same key on every restart. Losing the key makes encrypted history unreadable. Demo databases are separate and plaintext; JSONL and CSV exports are plaintext too.

This release replaces the earlier private development releases. Install its newly rebuilt archives before connecting live traffic; versions from the discarded development history do not identify these binaries.

The Python and JavaScript SDK checks use a loopback mock and dummy credentials; they do not establish live-provider compatibility. Historical load measurements predate encrypted history and are not current capacity claims. macOS and Windows executables are not publisher-signed or notarized; archive checksums establish downloaded-byte consistency, not publisher identity. OS security policies may require approval to run an unsigned executable. No automatic analytics or event uploads are added.

## Validation

Publishing requires all six native jobs to pass formatting, Clippy, Rust tests, browser interaction/accessibility checks, both pinned SDK fixtures, live/demo startup and embedded-dashboard checks. Windows jobs also verify the real PowerShell installer, repeat upgrades, version pinning, checksum failures, missing downloads, invalid archive contents and mismatched executable versions.
