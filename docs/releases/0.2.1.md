Jev Observer 0.2.1 adds a researched decision-model catalog, provider-specific validation and offline capture imports from PR #4.

## Model connections and capture imports

- Browse 38 decision-model families and serving integrations in the dashboard, with connection instructions and documented model names: 22 HTTP proxy paths and 16 mapped capture paths.
- Validate documented provider differences, including rounded distributions, wider score rubrics, structured legends, missing confidence and modal scores, while preserving original results.
- Import explicitly identified System One request/response captures. Offline converters support NanoJev, AgentJev, AnyJev, SemIf and AutoTrust with explicit question mappings and complete reported distributions.
- Recompute imported validity, deduplicate by event identity and exclude recognized input and media fields by default.

The catalog records an October 3, 2026 source snapshot covering 27 repository commits and 11 pinned model cards. Newly cataloged integrations have source and synthetic-fixture coverage; live inference remains unverified. Existing live evidence covers Jev through OpenRouter and Laya. Each Observer process still uses one fixed upstream. See the [model guide](https://github.com/LimePencil/jev-observer/blob/v0.2.1/docs/models.md) and [research evidence](https://github.com/LimePencil/jev-observer/tree/v0.2.1/research/models).

## Upgrade

Stop Observer cleanly and back up the database and any SQLite sidecar files before replacing the executable. Keep the same saved `JEV_OBSERVER_DB_KEY`. Rerun the Unix installer with `--version 0.2.1` or the PowerShell installer with `-Version 0.2.1`. See the [installation guide](https://github.com/LimePencil/jev-observer/blob/v0.2.1/docs/installation.md).

Credential storage and downgrade limitations from 0.2.0 still apply. macOS and Windows executables remain unsigned.

## Validation

PR validation passed 112 Rust tests (one existing timing benchmark ignored), 46 browser tests, two packaged-backend browser tests, six capture-converter tests, formatting, Clippy, dashboard build, installer and release-metadata checks, dependency notices and SDK compatibility checks. The release workflow repeats native build and verification gates for Linux, macOS and Windows on x86_64 and ARM64 and verifies all six archives plus SHA-256 checksums before publication.
