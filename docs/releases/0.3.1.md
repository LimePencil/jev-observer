# Jev Observer 0.3.1

0.3.1 improves broad-history dashboard queries and updates Linux saved-credential support. It includes the two PRs merged since 0.3.0.

## Changes

- [#128](https://github.com/LimePencil/jev-observer/pull/128): Add compact answer-statistics and answer-key indexes to reduce broad dashboard reads and repeated substring matching. Exact counts, ordering and search semantics are preserved, with bounded memory and the existing fallback for high-cardinality or narrow queries.
- [#127](https://github.com/LimePencil/jev-observer/pull/127): Port Linux Secret Service credentials to zbus 6 using two provenance-recorded local dependency patches, and update Tokio to 1.53.3. Saved-credential identities, encryption and staged approvals are preserved. CI now checks persistent credential interoperability with published 0.3.0, including upgrades, rollback and keyring-daemon restarts.

## Performance and upgrade notes

On the paired encrypted 100,000-request / 300,000-answer fixture, all-history query medians improved from 442 to 368 ms and search from 620 to 516 ms; all nine complete JSON comparisons matched 0.3.0. The final million-request / three-million-answer HTTP fixture passed all 26 correctness checks. These shared-host measurements are workload-specific, not latency or capacity guarantees; see the [broad-history validation evidence](../../reports/validation/broad-history/README.md).

The new indexes are created automatically on first startup. The 100,000-request migration took 6.51 seconds and increased database size by 6.73% in the measured fixture. Larger histories can take substantially longer and need additional disk space, including temporary index-building space and WAL. Both indexes add write work. Existing tables remain readable by older versions.

Stop Observer and preserve the encrypted workspace, database key and previous executable before upgrading; see [installation and rollback](../installation.md#history-backups-and-downgrades). The 45-second dashboard deadline and slow-query feedback are unchanged.

## Release verification

The merged runtime passed 194 Rust tests (two intentionally ignored), Clippy, browser/accessibility, packaged-backend, SDK and Linux credential interoperability checks. Archived upgrade evidence records 36 passing checks against published 0.1.0, including rollback and backup restore.

Publication requires the tag workflow to pass native Rust, UI, packaged-browser, SDK, upgrade and archive verification on Linux x64/ARM64, macOS Intel/ARM64, and Windows x64/ARM64. Downloads include six platform archives and SHA256SUMS. macOS and Windows binaries remain unsigned.
