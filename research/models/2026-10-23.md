# Decision model additions, October 23, 2026

This is an incremental review for 0.4.0. The catalog now has 54 family and runtime entries: 16 additions, updated TypeSafe and Jev-Omni contracts, and 36 entries retaining their October 3 review date. [The source register](2026-10-23-sources.json) pins primary documentation, repository revisions and file hashes. [Synthetic fixtures](2026-10-23-fixtures.json) express selected boundary cases without executing provider code, downloading weights or making inference calls. Runtime availability, account permissions, model quality and calibration were not measured.

The source register distinguishes native helper facts from hosting/runtime assumptions. For example, the Workers AI generic REST documentation describes `result` and `success`, while the Clef model page demonstrates a direct Worker binding result; no authenticated REST inference was observed. Source compatibility is not evidence of deployed serialization precision.

The additional discovery lead [Bespoke Nimble v3 on Ollama](https://ollama.com/library/nimble) was not promoted into a new native contract. Its current runtime and weight terms differ from the older catalog snapshot; licenses apply separately to code, base weights and checkpoints. This review is not an exhaustive census or popularity ranking.
