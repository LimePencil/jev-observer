# Evidence matrix: 100 Jev repositories

Reviewed September 22, 2026. [Findings and methodology](README.md). [CSV](projects.csv) · [pinned source manifest](manifest.json) · [manual annotations](annotations.tsv).

Observed use and existing visibility are static-review findings from code excerpts and project documentation. Proposed help is our hypothesis, not a maintainer request or measured benefit. Each row links its principal implementation evidence and README; the manifest lists additional collected sources. Patterns describe the main grouping challenge observed, not every question in a repository. Rows 91–100 are evaluation-oriented projects; row 96 is an artifact/report study. No applications or benchmarks were run.
